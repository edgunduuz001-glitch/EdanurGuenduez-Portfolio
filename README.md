# Edanur Gündüz — Portfolio

GitHub için hazır site paketi — 9 Ekim 2026.

## Yükleme

1. ZIP dosyasını açın.
2. İçindeki `index.html`, diğer HTML sayfaları, `assets`, `home-assets`, `styles` ve `scripts` klasörlerini aynı yapıyı koruyarak mevcut GitHub deposunun kök dizinine kopyalayın. Aynı adlı dosyaları değiştirin. Mevcut deponun `.git` klasörünü koruyun.
3. Değişiklikleri commit edip GitHub'a gönderin. GitHub Pages yapılandırması kök dizin üzerinden yayına devam edebilir.

ZIP dosyasının kendisini yüklemeyin; içeriğini yükleyin. `index.html` depo kökünde olmalıdır.

## Dahil edilen düzeltmeler

- Ana sayfadaki TCG Card UI Design görseli WEBSITE SON sayfasındaki Figma görseli, ölçeği ve kırpılmasıyla eşleştirildi.
- Proje girişlerinin yazı boyutları, sarı vurgu alanları ve boşlukları düzeltildi.
- Beş proje headerına Home, Work, About, Contact ve CV menüsü eklendi. Ana sayfa bağlantıları mobilde doğru bölümlere gider.
- Steal & Seal görselleri yeni PC mockuplarıyla değiştirildi. Karşılaştırma ve HUD işaretleri bu görsellere uyarlandı.
- Telefon, PC ve kart görselleri kendi türleri içinde ortak boyut sınırlarına getirildi. Galeri boşlukları azaltıldı; en-boy oranları korundu.

## İçerik ve kontrol

Altı sayfa, gerekli stil ve script dosyaları, görseller, videolar, fontlar ve İngilizce CV dahildir. Kullanılmayan eski dosyalar, arşivler ve yerel Git geçmişi pakete dahil edilmedi.

Beş proje sayfası 1440, 1223, 966, 760, 390 ve 320 px genişliklerde kontrol edildi. Paket oluşturulurken yerel dosya bağlantıları doğrulandı.
